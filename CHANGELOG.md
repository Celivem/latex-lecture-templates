## [0.1.0] - 2026-11-15

First public release.

### Added

- `styles/codex_notes.tex` for lecture notes: chapter header, numbered
  sections with an English subtitle, definition / theorem / derivation /
  example blocks sharing one numbering sequence, key-result, chapter-question,
  note and extension boxes.
- `styles/codex_solutions.tex` for worked solutions: problem headings in the
  table of contents, the original English problem statement in a grey serif
  box, result and note boxes.
- Two examples (`examples/`), each producing a 3-page PDF with
  TeX Live 2026, and the font setup through `\codexfontpath`.
- English and Traditional Chinese READMEs with a full reference of both
  templates, `CITATION.cff` and this changelog.
